# 按文件夹分类整理（CourseOrganizer）

> MoviePilot（V2）操作插件 —— 稳定待整理目录后，结合 TMDB/豆瓣，把课程/影视分类整理到**电视剧 / 电影 / 儿童**媒体库。

- **插件 ID**：`CourseOrganizer`
- **作者**：[OneBigMoon](https://github.com/OneBigMoon)
- **版本**：`1.7.12`（V2 插件；V3 为 `2.0.2`）
- **官方插件市场 PR**：[jxxghp/MoviePilot-Plugins#1157](https://github.com/jxxghp/MoviePilot-Plugins/pull/1157)
- **仓库**：<https://github.com/OneBigMoon/moviepilot-v2-course-organizer>

## 为什么需要它

MoviePilot 的"整理"必须先把文件识别成某部**有 TMDB/豆瓣 ID 的媒体**，识别不了就拒绝搬移。而 **儿童课程这类资源通常不在 TMDB/豆瓣 上**，所以它们永远走不通原生整理。

本插件针对这条补了两个能力：

1. **有媒体 ID 的**（影视）：搜索 / 关联 TMDB → 交给 MoviePilot 原生整理。
2. **没有媒体 ID 的**（如儿童课程）：`保存并整理` 时**按标题直接把源目录搬到所选目标媒体库**，并把文件重组为标准剧集结构 —— 目录/建议名/**`Season 1`/`S01E01.mp4`**（多集合并文件保留为 `S01E01-E02.mp4`）。

## 功能一览

- 待整理目录稳定后自动/手动预览，识别来源（TMDB、豆瓣、DeepSeek、本地）。
- 进入页面**自动查找 TMDB 候选**；支持按**修改后的建议名称**搜索。
- 选定候选后下拉显示所选结果，**建议名称自动跟随 TMDB 标题**。
- 操作结果/失败提示显示在**对应行**（而非只在顶部），精简 UI。
- 无媒体 ID（课程）条目也能"保存并整理"：**直接搬移到所选媒体库** + 归一为 `Season N/S01E01`。

## 使用流程

1. 打开插件，进入"安全预览与人工确认"。
2. 查看识别来源与建议名称。
3. 需要时点击"按名称搜索 TMDB"，从候选下拉选择作品（无需手填 TMDB ID）。
4. 修改建议名称、选择目标媒体库，点击"保存并整理"。
5. 有 TMDB/豆瓣 ID → MoviePilot 原生整理；课程等无 ID → 直接搬移 + 季/集归一。

## 智能助手

先在 MoviePilot **设置 → 智能助手** 中配置并启用模型（如 DeepSeek），再打开插件设置中的
**启用智能助手**。开启后，复杂目录名会先提取适合 TMDB 的搜索词，再复核候选；智能助手
不可用时自动回退到本地规则与人工确认。

## 目录配置

在 MoviePilot：**设置 → 存储 & 目录**，至少准备三条明确规则（来源可同一目录）：

| 用途 | 媒体类型 | 来源示例 | 目标示例 |
|---|---|---|---|
| 电影 | 电影 | `/media/incoming` | `/media/movies` |
| 电视剧 | 电视剧 | `/media/incoming` | `/media/tv` |
| 儿童课程 | 电视剧 | `/media/incoming` | `/media/courses` |

儿童课程规则的目录别名应包含"儿童 / 少儿 / 幼儿 / 课程"等字样，插件才能无歧义识别媒体库类型。搬运方式、重命名、刮削、通知等都在这三条 MoviePilot 规则里配置，插件只读取不覆盖。

> 人工复核期间，不要让同一来源目录同时被 MoviePilot 自动监控整理，否则文件可能在确认前被原生监控任务处理。

## 安全边界

- 人工复核 API 仅允许启用中的超级管理员访问。
- 原始目录、预览版本与目录树指纹必须与确认时一致。
- 只有成功的搬移/原生整理后才消费决定并标记完成；部分失败时阻止重复确认。
- 未经明确授权不会执行真实媒体移动、提交、推送或部署。

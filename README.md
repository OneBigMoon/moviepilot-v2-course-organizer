# MoviePilot 课程自动整理（V2）1.5.3

### 更新说明

- 将单一输出目录升级为三个真实目标媒体库：电视剧、电影、儿童。
- TMDB/豆瓣提供标题和媒体类型，DeepSeek 复核儿童受众与最终分类；分类置信度低于 `0.90`、类型冲突或 AI 不可用时只记录预览，不移动。
- 旧配置 `output` 仅在升级时迁移为 `children_output`，页面和运行逻辑不再使用单一输出目标。
- 优化深色主题下配置页顶部状态条：改为透明底+边框，避免浅灰低对比度。
- 收紧配置页顶部内容区的垂直间距，减少底部区域被原生 footer 截断的视觉问题。
- 修复 Basic 侧边栏下方的第一行文本字段标签重叠：给基础标签页中 `incoming` 文本框加上 `mt-2` 垂直间距，避免小高度视图冲突。
- 修复小高度配置弹窗中的目录路径截断与底部操作区可达性：左栏独立滚动、目录流比例调整为 `4/1/7`，长路径支持换行，三个目标媒体库最多显示两行。
- 高级设置默认折叠，普通使用路径先聚焦目录、预览、异常处理和自动整理。
- 新增可检索的 `CourseOrganizer[event=...]` 运行日志，覆盖扫描、下载未完成阻断、分类保留、预览、命名阻断和移动阶段；新事件不记录完整输入/输出根路径、密钥或服务请求响应。

## 一、功能

- 扫描 `incoming` 下的**一级子目录**作为待整理媒体目录。
- 递归收集课程目录中的媒体文件（`.mkv/.mp4/.avi/.mov/.wmv/.flv/.m4a/.m4v`）与字幕文件（`.srt/.ass/.ssa/.sub/.vtt`）。
- 按课程内文件名做自然排序，重命名为：
  - `<课程名> - S01E001.ext`（第一季）
  - `<课程名> - S01E001-E002.ext`（一个文件连续包含第 1-2 集，不拆分视频）
  - `<课程名> - S02E001.ext`（第二季）
  - `<课程名> - S01E001.srt`
- 识别分类后放入：`tv_output|movie_output|children_output/<规范名>/Season N/`；优先使用目录中的季节标识（如 `Season 2` / `S02` / `第2季` / `第二季`），未检测到则默认 `Season 1`。
- 仅接受清晰的前置集数范围（如 `1-2.mp4`、`E01-E02.mp4`、`第1-2集.mp4`）；范围会一次性保留整段集数，避免与现有集数重叠。
- 相同目标文件名自动加 `_1/_2` 后缀避免覆盖。

## 二、稳定性与安全规则

- 课程目录在**连续两次快照一致**且立即再进行一次快照确认后才会进入整理。
- 目录中存在不完整后缀文件（`.partial/.part/.tmp/.crdownload/.incomplete/.!qb`）时，**整门课程不执行**，不会有文件搬移。
- 即使存在字幕文件只要媒体文件无变化，会与其基名匹配并随对应分集一起移动。
- 目标目录已有同名文件时会自动改名，不会覆盖原文件；同一作品在不同源下可在“同一作品互证”条件下提升分值。
- 课程目录只有在清空后才会删除；保留任何其他文件（例如 `.txt`）会阻止源目录清理。

## 三、注意事项

- 默认输入：`/volume1/未整理`。
- 默认电视剧目录：`/volume1/TV`。
- 默认电影目录：`/volume1/Movies`（页面显示“电影”）。
- 默认儿童目录：`/volume1/儿童`。
- 插件只扫描 `incoming`；三个媒体库仅作为经过安全门槛后的写入目标，不会被反向扫描。
- Off 模式：不做元数据检索、AI 和网络访问。
- Preview 模式：完成两次快照并调用命名决策，仅记录候选与建议，不创建新目录/移动。
- Apply 模式：先进行同样决策，自动阈值通过则按外部元数据命名，不通过时使用本地目录名。

## 四、配置项

- `enabled`：是否开启。
- `run_once`：请求排队期间保持为 true，在异步回调取得执行权或显式停止时复位为 false；即时配置重载不会取消已排队回调，重复请求只保留一次。
- `incoming`：待整理源目录。
- `tv_output`：电视剧目标根目录，默认 `/volume1/TV`。
- `movie_output`：电影目标根目录，默认 `/volume1/Movies`。
- `children_output`：儿童目标根目录，默认 `/volume1/儿童`。
- `interval`：轮询间隔（秒）。

## 智能命名（预览/应用）

- 解析示例：
  - `《飘零叶 Tumble Leaf》儿童早教动画，全美获奖冒险故事启蒙精品`
  - `黑冰 (2001) 高清修复版 未删减`
  - `熊孩子国学故事`

- 数据源与评分：默认使用 MoviePilot 已启用顺序中的 `themoviedb` 与 `douban`。
  - 最多 3 个查询标题、每个查询最多 2 个源、每源前 5 条、总计去重后最多 20 条。
  - 确定性分值并支持同一作品的 TMDB/豆瓣跨源互证加分。
  - 分数低于 70 仅保留本地名称。

- 可选 AI 复核（依赖 MoviePilot 当前 AI 提供商配置；未另存储或持有独立 DeepSeek Key，未开启则不调用）：
  - 仅在 `review` 状态生效。
  - AI 只可选择白名单候选，不可伪造标题/年份/ID。
  - 置信度低于 `0.85` 不采纳。

- 人工覆盖：
  - `raw_dir => local:xxx` 固定本地名
  - `raw_dir => query:xxx` 重算查询并保留人工确认态
  - `raw_dir => candidate:themoviedb:65047:tv` 固定候选
  - `raw_dir => ignore` 跳过目录

- 输出格式
  - 外部命中：`<规范名> (<年份>)`，文件名不包含年份。
  - 本地兜底：`<目录名> (<年份>)`，年份来自原名解析。
  - 可选 `append_tmdb_id`：`<规范名> (<年份>) [tmdbid-xxxx]`

## 缓存与冲突策略

- 最近 500 条元数据搜索缓存、500 条身份映射、200 条预览历史、100 条 AI 异常历史。
- 先有 `legacy` 输出目录与新决策目录不一致时阻塞移动，避免拆分。

# MoviePilot 课程自动整理（V2）

## 一、功能

- 扫描 `incoming` 下的**一级子目录**作为课程目录。
- 递归收集课程目录中的媒体文件（`.mkv/.mp4/.avi/.mov/.wmv/.flv/.m4v/.m4a`）与字幕文件（`.srt/.ass/.ssa/.sub/.vtt`）。
- 按课程内文件名做自然排序，重命名为：
  - `<课程名> - S01E01.ext`（第一季）
  - `<课程名> - S02E01.ext`（第二季）
  - `<课程名> - S01E01.srt`
- 放入：`output/<课程名>/Season N/`，优先使用目录中的季节标识（如 `Season 2` / `S02` / `第2季` / `第二季`），未检测到则默认 `Season 1`。
- 相同目标文件名自动加 `_1/_2` 后缀避免覆盖。

## 二、稳定性与安全规则

- 课程目录在**连续两次快照一致**且立即再进行一次快照确认后才会进入整理。
- 目录中存在不完整后缀文件（`.partial/.part/.tmp/.crdownload/.incomplete/.!qb`）时，**整门课程不执行**，不会有文件搬移。
- 即使存在字幕文件只要媒体文件无变化，会与其基名匹配并随对应分集一起移动。
- 目标目录已有同名文件时会自动改名，不会覆盖原文件。
- 课程目录只有在清空后才会删除；保留任何其他文件（例如 `.txt`）会阻止源目录清理。

## 三、注意事项

- 默认输入：`/volume1/未整理`。
- 默认输出：`/volume1/儿童`。
- 插件仅处理课程目录，**不会**扫描或触碰 `/volume1/TV`。
- 不做 TMDB/刮削/网络抓取，不做元数据补全。

## 四、配置项

- `enabled`：是否开启。
- `run_once`：启用时在本次初始化后异步执行一次后复位。
- `incoming`：课程源目录。
- `output`：课程目标根目录。
- `interval`：轮询间隔（秒）。
